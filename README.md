# Image Caption Generator

An image captioning system that uses the BLIP model to generate descriptive captions for images.

## What it does

The project takes an input image and generates a natural-language caption describing the image.

## How to use

Run the notebook and provide an image as input.

The BLIP model processes the image and generates the caption.

## Built with

Python, BLIP, Hugging Face Transformers, PyTorch and PIL.
